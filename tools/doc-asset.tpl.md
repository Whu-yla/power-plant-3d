## 2 资产内容与版本

本资产由"数据 + 渲染 + 文档"三部分组成：

1. **数据层**：`plant-data.js`，唯一数据源，含 `meta`（标题、来源、单位、原点）、{{N_STRUCT}} 个构件（`structures`）、{{N_ROADS}} 段道路四边形（`roads`）、厂区边界折线（`boundary`，{{N_BOUNDARY}} 点）、{{N_TREES}} 个绿化点（`trees`）。
2. **渲染层**：`index.html` / `style.css` / `builders.js` / `main.js` + `vendor/`（本地 Three.js 与 OrbitControls），提供旋转缩放平移、双击聚焦、信息面板、线框/光照/标注/显隐开关，以及 `window.PlantApp` 扩展钩子。
3. **文档层**：`readme.md`（项目说明，含构件参数清单、估算项清单、集成与扩展说明）与本文件（归档资产说明）。

版本规则：`plant-data.js` 中数据字段或构件数量变化记为数据版本升级；仅界面/交互调整记为界面版本升级。本版为 **v1.0（首次归档）**，构件数量与坐标一经发布，修改需在变更记录中留痕。

## 5 坐标标定证据链摘要

1. **图纸坐标**：测量坐标（东 E / 北 N），主图幅约 E 2900900–2902800、N 2548300–2549700（约 1,900 m × 1,400 m），坐标绝对值为百万级。
2. **冷却塔几何反算**：冷却塔由**两个顶点、bulge = 1 的 LWPOLYLINE 半圆**绘制，圆心角 180°，两顶点即直径端点。反算得圆心 (2901391.4, 2549265.3)、(2901541.1, 2549374.0)，外圈半径 **51 m**（直径 102 m），内圈半径 40 m；两塔圆心距 **185.0 m**，与图纸"两塔间距约 185 m"一致。
3. **面积量纲校验**：π×51² = **16,342 m²**，与《二期工程建构筑物一览表》"127 循环水冷却塔 16,400 m²"相对误差 0.35% → 判定 **1 图纸单位 = 1 米**，全图按米解释。若按毫米解释，塔径仅 0.102 m，面积差 6 个数量级，可排除。
4. **交叉验证**：制氢站 31.5×31.5 = 992 m²（一览表 1,000 m²）；汽机房 175×34.4 = 6,020 m²（一览表 6,020 m²）；烟囱占地 210 m² → 底径 16.4 m；两座冷却塔合计 16,340 m²（一览表 16,400 m²）。标定结论一致。
5. **三维世界坐标**：`世界坐标 = 图纸坐标 − 原点(2900800, 2548300)`，X 为东向、Y 为北向、Z 为高度（m）。渲染到 Three.js 时按 Y 轴向上换算为 `(X, Z, −Y)`。
6. **精度**：实体坐标保留 0.1 m 量级，同一边多次量测偏差 ≤ 0.5 m；半径取整 51 m 后与一览表面积偏差 0.35%；图纸无量测高程，全厂按单一地坪（Z = 0）处理。

## 8 已知偏差与复核项

### 8.1 已知偏差

| 类别 | 情况 | 影响与处置 |
|---|---|---|
| 尺寸估算 | {{N_EST}} 个构件的尺寸/高度为常规工程估算（清单见 readme 第 5 节） | 影响体量与天际线，不影响构件平面相对位置；已逐项注明标记 |
| 烟囱高度 | 取 210 m（按一览表面积 + 600 MW 常规参数反推底径 16.4 m） | 直接影响天际线与限高判断，优先复核 |
| 冷却塔塔高 | 取 130 m（塔径 102 m 为实测） | 塔高影响循环水方案比选，需查工艺图 |
| 锅炉房面积 | 单台 3,033 m²（图面量测），一览表两台合计 8,840 m²，差约 2,774 m² | 口径可能不同（是否含烟风道/除渣），需核对后修正轮廓或说明 |
| 条形煤场 | 两座合计 11,880 m²，一览表"煤场及干煤棚"合计 30,000 m² | 可能含斗轮机轨道与扩建区，需核对煤场范围 |
| 干灰库直径 | 数据取 Ø17 m，图面文字标注 Ф15 m | 建议以图面文字为准修正 |
| 卸煤槽位置 | 无编号标注点，按铁路线走向推定 | 位置与尺寸均待复核 |
| 未建模设施 | 115 渣库、137–142 转运站、#1–#5 输煤栈桥 | 需施工图或现场补充后新增 |
| 竖向 | 无高程数据，全厂单一地坪 | 竖向设计、坡度、防洪标高不在本资产范围 |
| 道路 | 双线配对在路口处可能缺面，宽度 3.4–13.6 m | 抽查主干道宽度与转弯半径 |

### 8.2 复核优先级

1. 烟囱高度与底径（ST-108）、冷却塔塔高（ST-127A）——影响厂区天际线与工艺方案；
2. 500 kV 配电装置场地划分（ST-119）——影响出线走廊；
3. 锅炉房、条形煤场面积口径（与一览表差异项）；
4. 未定位设施（115 渣库、136 卸煤槽、137–142 转运站）的位置补录；
5. 各单体建筑高度、施工临建平面尺寸——按需复核，不影响总体关系。

完整复核清单（15 项）见 `readme.md` 第 11 节。

### 9.2 运行方式

- 单机演示：双击 `src/3d-powerplant/index.html`（`file://`，无需服务器）；
- 后台集成：整目录部署到 Hermes 8090 静态目录（如 `/plant3d/`），后台页面 `iframe` 引用 `/plant3d/index.html?embed=1`；
- 交互：左键旋转、滚轮缩放、右键平移、双击聚焦、点击弹出信息面板；工具栏提供线框、光照、标注、构件显隐与复位视角开关。

### 9.3 接口约定

- 全局对象 `window.PlantApp`：`focusOn(id)`、`setVisible(id, bool)`、`setAlarm(id, level)`、`setStatus(id, 'normal'|'warning'|'alarm'|'offline')`、`addInspectionPoint({id,name,x,y,z,status})`（`x/y` 为世界坐标）、`select(id)`、`getSelected()`、`resetView()`、`onSelect` 回调，以及 `scene / camera / renderer / controls / structures / data` 等只读引用；
- `postMessage` 协议：父→子 `plant:focus`、`plant:alarm`、`plant:status`、`plant:visible`、`plant:inspect`；子→父 `plant:selected`（选中回传，`targetOrigin` 固定为 `http://127.0.0.1:8090`）；
- 安全要求：三维页面当前不校验 `ev.origin`（便于 `file://` 调试），HTTP 集成后应加源白名单；父页面校验子页面消息的 `origin` 与 `type`；`targetOrigin` 不使用 `*`；CSP 放行同源 `frame-src`；集成部署走 HTTP，不以 `file://` 作为 iframe 源。

### 9.4 维护责任与依赖

- 数据维护：修改 `plant-data.js` 后需同步更新 `readme.md` 第 4、5 节统计与本文第 7 节，并按第 8 节复核受影响项；
- 渲染维护：新增 `shape` 类型需在 `builders.js` 注册；替换 GLB 需补充 `GLTFLoader.js` 到 `vendor/`；
- 依赖固定：Three.js 与 OrbitControls 使用本地 vendor 版本，不随外部 CDN 升级；如需升级，必须回归检查 `LatheGeometry`、`InstancedMesh` 与拾取行为；
- 失效条件：源图纸更新、厂区总平面调整、设备增删时，本资产需重新解析或在数据层增量修订，并在变更记录中登记。
